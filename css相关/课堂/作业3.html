HTML定义列表与iframe演示

探索HTML中定义列表(dl/dt/dd)和内联框架(iframe)的强大功能

定义列表 (Definition List)

定义列表用于展示术语和其对应的描述，非常适合创建词汇表、FAQ或属性列表。

基本示例

HTML
超文本标记语言，用于创建网页的标准标记语言
CSS
层叠样式表，用于描述HTML元素在屏幕上的显示方式
JavaScript
一种轻量级的编程语言，使网页具有交互性

代码示例

<dl>
  <dt>术语</dt>
  <dd>术语的详细描述</dd>
</dl>

交互式示例

响应式设计
使网站能够在不同设备和屏幕尺寸上良好显示的设计方法
语义化HTML
使用具有明确含义的HTML标签来构建网页结构

定义列表的特点

  • 语义化强，明确表示术语和定义的关系
  • 支持多个术语对应一个定义
  • 支持一个术语对应多个定义
  • 适合创建词汇表、FAQ和属性列表

内联框架 (iframe)

iframe允许在当前页面中嵌入另一个HTML文档，常用于嵌入地图、视频或其他网页内容。

基本示例

代码示例

<iframe src="url" width="100%" height="300">
  <p>您的浏览器不支持iframe</p>
</iframe>

动态控制示例

iframe属性详解

src
指定要嵌入的文档URL
width
设置iframe的宽度
height
设置iframe的高度
frameborder
控制是否显示边框（HTML5中已废弃）
sandbox
限制iframe内容的安全策略，如禁止脚本、表单提交等
allow
指定允许的功能，如摄像头、麦克风等
referrerpolicy
控制发送referrer信息的方式
allowfullscreen
允许iframe内容全屏显示
loading
控制iframe的加载方式（lazy/eager）
name
为iframe指定名称，可用作链接的目标
