JavaScript 基础 ▼

JavaScript 是一种轻量级的解释型或即时编译型的编程语言。

  • 变量声明：var、let、const
  • 数据类型：字符串、数字、布尔值、对象、数组等
  • 函数定义和调用
  • 事件处理
// 示例代码
const message = "Hello World";
console.log(message);
DOM 操作 ▼

文档对象模型 (DOM) 是HTML和XML文档的编程接口。

  • 元素选择：querySelector、getElementById
  • 内容修改：innerHTML、textContent
  • 样式操作：style、classList
  • 事件监听：addEventListener
// DOM 操作示例
const element = document.getElementById('myElement');
element.style.color = 'red';
异步编程 ▼

异步编程允许程序在等待操作完成时继续执行其他任务。

  • 回调函数
  • Promise 对象
  • async/await
  • Ajax 请求
// Promise 示例
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data));

前端开发框架 ▼

现代前端开发中常用的框架和库：

  • React - Facebook开发的UI库，组件化开发
  • Vue - 渐进式JavaScript框架，易于上手
  • Angular - Google开发的完整框架，企业级应用
  • Svelte - 编译时框架，运行时性能优秀

选择框架时需要考虑项目规模、团队技能和性能要求。

CSS 预处理器 ▼

CSS预处理器扩展了CSS语言，增加了变量、嵌套、混合等功能。

  • Sass - 最流行的预处理器，功能强大
  • Less - 语法简单，易于学习
  • Stylus - 灵活的语法，代码简洁
// Sass 示例
$primary-color: #007bff;
.button {
  background: $primary-color;
  &:hover {
    background: darken($primary-color, 10%);
  }
}
构建工具 ▼

现代前端开发离不开构建工具，它们帮助优化工作流程。

  • Webpack - 模块打包器，功能全面
  • Vite - 新一代构建工具，开发服务器快
  • Parcel - 零配置构建工具，简单易用
  • Rollup - 专注于库打包，输出更小

选择合适的构建工具可以显著提高开发效率。
